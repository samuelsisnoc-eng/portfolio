# Samuel C. Sisno - Portfolio

A one-page responsive portfolio website (Activity: Responsive Design).

## Sections
Header, Hero, About, Services, Projects, Contact, Footer

## Responsive breakpoints
- Desktop: 1200px (3-column services, side-by-side contact)
- Tablet: 768px (2-column services, stacked contact)
- Mobile: 375px (single column, hamburger menu)

- `index.html`
- `style.css`
- `script.js` (dark mode toggle + mobile menu)

- `screenshots/` (desktop, tablet, mobile)
